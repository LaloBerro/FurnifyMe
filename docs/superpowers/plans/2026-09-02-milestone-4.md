# Milestone 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Versions panel with thumbnails, a standalone selector window, a retroactive
mirror tool, linked copies, face-on ortho grids with a density setting, 8-direction
sketch snap, an exact top view, and a path-traced render mode with a settings panel.

**Architecture:** Seven phases on the existing MainWindow/OcctViewWidget/DocumentModel/
FurnitureStore stack. Geometry and group/pairing state stay Qt-free and headless-tested;
UI phases consume a user-picked HTML mockup as their visual contract.

**Tech Stack:** C++17, Qt 6.11 Widgets, OCCT 8.0.1, CMake presets (`windows`,
`windows-headless`).

**Spec:** `docs/superpowers/specs/2026-09-02-milestone-4-design.md` — the spec is the
binding authority; this plan argues from it.

## Global Constraints

- **PHASE GATE (controller duty, not a task):** after the last task of each phase —
  suite green, commits done, `furnifyme.exe` rebuilt (never killing a running instance;
  check `tasklist` first) — STOP and wait for the user's test verdict. No next-phase
  dispatch without it.
- **MOCKUP GATE (controller duty):** phases 1, 2, 3, 7 begin with an HTML-options
  artifact round; the picked option is pasted into the affected tasks' dispatch as the
  visual contract. Tasks marked `[MOCKUP-INPUT]` cannot be dispatched before the pick.
- CLAUDE.md binds throughout: vocabulary sweep (banned words incl. `Fuse`, `Solid`,
  `OCCT`, `mm3`, `(s)`, `Merge`, `Join`, `bevel`, word-boundary `round`/`flatten`),
  no modal dialogs, opaque paint family, `Theme::wholeDevicePixels`/`snapToDevicePixels`,
  `updateActions()` as sole availability authority, Notes silenceable / Failures never,
  `Measure` for every number, checkpoint taxonomy, derive-never-store, no Qt in
  `furnify_geometry`, `BooleanResult::ok==false` carries a null shape.
- Tests: `gui_smoke` (in-process events only, no OS input; check-floor may only rise)
  and the headless suites via `windows-headless` preset. New geometry/document logic
  lands with headless tests BEFORE UI wiring.
- Suite runs write snapshots to a scratch dir that exists beforehand (`V3d_View::Dump`
  pitfall). Kill no user processes; stray `gui_smoke.exe` from OUR runs may be killed.
- Commits per task, repo voice, trailer:

## Phase 4 — Linked copies

### Task 4.1: Link groups in the document (Qt-free first)

**Files:**
- Modify: `src/DocumentModel.h`, `src/DocumentModel.cpp`, `src/ModelingOps.h/.cpp`
  (only if a placement helper is needed there), headless test file as in 3.1.

**Interfaces:**
- Produces: in `State`: `std::map<int, LinkGroup>` where
  `LinkGroup { int anchorId; std::map<int, gp_Trsf> placement; }` (placement maps anchor
  frame → member frame; anchor's own is identity). API:
  `createLinkedCopy(int sourceId, const gp_Trsf& offset)` → new id;
  `linkExisting(const std::vector<int>& ids)` (first = anchor; others' shapes replaced by
  anchor's shape translated centre-to-centre — v1 per spec) → checkpointed;
  `unlink(int memberId)`;
  `propagateLinkedEdit(int editedMemberId, const TopoDS_Shape& newShape)` — anchor shape
  := placement(edited)⁻¹ · newShape, every member := placement(m) · anchor, one State
  mutation (caller owns the checkpoint). Mirror∩link refused:
  `linkExisting`/`createLinkedCopy` on a paired body → error result with a reason string.

- [ ] **Step 1: failing headless tests** — copy: shape equal under its placement, group
  membership, undo removes copy+membership; link-existing: others' volumes become the
  anchor's, translation-only placements, one undo restores originals byte-identically
  (State round-trip); propagation: edit a member (e.g. a `pullFace` result), assert
  every member is the transformed anchor to tolerance, placements unchanged; unlink;
  mirror∩link refusal both directions.
- [ ] **Step 2–5: fail → implement → green (headless) → commit.**
